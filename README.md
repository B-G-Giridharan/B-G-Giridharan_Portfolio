# Giridharan — Interactive Portfolio

A premium, experimental portfolio for B G Giridharan inspired by hypothesis-driven editorial websites, with cinematic scroll motion, interactive project proof, and a 3D-style portfolio room.

This folder is a complete BG project. Everything the app needs is in these files: pages, API routes, database migrations, seed data, and the BG.toml manifest that declares the services and keys it uses.
